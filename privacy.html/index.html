Privacy Policy

Effective date: August 11, 2026

This policy covers the Dona Onça Publishing Tool, a personal, single-user desktop application that automates the publishing of video clips to social media accounts owned by the operator of the Dona Onça channel (including the TikTok account @donaoncambl).

Who uses this application

Only its owner. The application is not distributed, sold, or offered to the public. It has no user registration, no third-party users, and no web service — it runs locally on the owner's personal computer.

What data is handled

  • OAuth tokens issued by the social platforms (TikTok, YouTube, Meta) when the owner authorizes their own accounts. Tokens are stored locally on the owner's computer, in a folder excluded from any code repository or backup, and are used exclusively to publish the owner's own content through each platform's official API.
  • Basic profile information (display name) is read once at connection time, solely to confirm which account was authorized. It is shown in the local console and not stored beyond the OAuth tokens.

What is NOT done

  • No data about any third party is collected, stored, or processed.
  • No data is sold, shared, or transmitted to anyone. The application communicates only with the official API endpoints of the platforms the owner connected.
  • No analytics, no tracking, no cookies. This page itself is a static document and sets no cookies.

Data deletion

Revoking the app's access in the platform's own settings (for example, TikTok > Settings > Security > Apps) immediately invalidates its tokens. Deleting the local token files removes all stored data.

Changes

If this policy changes, the updated version will be published at this same address with a new effective date.
